This is a simple Note Api Built with Node.js, Express and Typescript.

Users can register, login, access and manage their personal notes.
The data is stored in JSON files for now

Tech used are; Node.js, Express, Typescript, 

Install Packages; npm install
Start the server; npm run dev

How it works; Postman=> Routes=> Controllers=> Services=> JSON File
Routes will decide which controller to call, Controllers will check the request, Services read and write to user.json or notes.json
